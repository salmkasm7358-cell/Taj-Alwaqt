# تاج الوقت | Taj-Alwaqt

واجهة متجر إلكتروني عربية لعرض الساعات وإدارة سلة تسوق تجريبية.

## التشغيل
1. فك ضغط المجلد.
2. افتح `index.html` في المتصفح، أو شغّل خادماً محلياً مثل Live Server في VS Code.
3. انتقل إلى صفحة المتجر لإضافة المنتجات إلى السلة.

## المزايا
- تصميم عربي RTL ومتجاوب مع الهاتف.
- صفحات الرئيسية والمتجر وتفاصيل المنتج والسلة وإتمام الطلب.
- بحث وفرز المنتجات.
- حفظ السلة محلياً في `localStorage`.

## ملاحظات مهمة
هذه نسخة واجهة أمامية تجريبية. لا يوجد دفع إلكتروني أو قاعدة بيانات أو إرسال فعلي للطلبات والرسائل. يلزم ربطها بخادم خلفي وبوابة دفع قبل استخدامها تجارياً.
الأسعار والصور والمنتجات الحالية أمثلة قابلة للتعديل.
